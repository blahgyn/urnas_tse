# Coloque aqui os boletins de urna do TSE

Copie para esta pasta os arquivos baixados do TSE, do jeito que vieram (`.zip`) ou já extraídos (`.csv`):

```
bweb_1t_SP_051020261403.zip    ← 1º turno
bweb_2t_SP_261020260742.zip    ← 2º turno
```

Os links para baixar estão no [README](../README.md#2-baixe-os-boletins-de-urna).
Pode colocar mais de um estado. Não misture eleições de anos diferentes na mesma pasta.

Estes arquivos não vão para o GitHub (estão no `.gitignore`).
